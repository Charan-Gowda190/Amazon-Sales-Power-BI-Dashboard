**Amazon Sales Analysis Dashboard | Power BI**

Project Overview
This project presents an interactive Amazon Sales Dashboard built using Microsoft Power BI to analyze sales performance, product information and customer reviews.

**Dashboard Pages**

**1. Sales Overview**
- Sales performance analysis
- Geographical sales visualization
- Sales trends and comparisons
- Interactive filters

**2. Product Review**
- Product review analysis
- Review-related visualizations

**3. Products**
- Product-level analysis
- Product details and filtering

4. **Info**
- Project information

 **Product Tooltip**
- Additional product information through interactive tooltips

**Tools & Technologies**
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
